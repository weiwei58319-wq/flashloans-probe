# flashloans-probe

Публичный стенд для поверки приборов. Здесь измеряются **свойства узлов RPC**,
и больше ничего.

## Что это и зачем

Проект Flashloans упирается в один вопрос: успевает ли конвейер увидеть
обновление цены оракула до того, как позицию заберут. Ответ зависит от того,
что умеет узел — отдаёт ли он пред-подтверждённые логи и на сколько раньше они
приходят. Это свойство **узла**, а не стратегии, и его можно мерить открыто.

Репозиторий служит каналом: задачи кладутся в `tasks/`, Colab прогоняет их
ноутбуком `colab_runner.ipynb`, вывод возвращается в `results/` коммитом.

## Граница — читать перед каждым коммитом

Репозиторий **публичный**. Всё, что сюда попадает, видно всем.

**Класть можно:**

- поддерживает ли endpoint `pendingLogs`, `newFlashblocks`, `logs`;
- на сколько миллисекунд одна подписка опережает другую;
- сколько сообщений в секунду даёт подписка и во что она обходится;
- любые характеристики сетевого пути и поведения узла.

Всё это описано в публичной документации провайдеров. Ничего собственного
в таких числах нет.

**Класть нельзя — никогда:**

- `m7.csv` и любые его производные;
- список рынков, их идентификаторы и доли;
- привязку «рынок → оракул», адреса оракулов, `morpho_markets_base.json`;
- пороги, знаменатель готовности, значения R;
- содержимое `config.yaml` и `thresholds.yaml`;
- URL endpoint'ов с ключами.

Это содержание стратегии. Один раз попав сюда, оно останется в истории git
даже после удаления файла.

**Правило проверки:** если число описывает узел — можно. Если оно описывает
рынок, позицию или решение — нельзя.

## Устройство

```
tasks/      скрипты для прогона
results/    вывод, по одному файлу на прогон
            INDEX.txt — оглавление, обновляется автоматически
colab_runner.ipynb
```

Каждый лог начинается с клейма среды. Прогон в Colab меряет путь
«дата-центр Google → узел», а не путь с рабочей машины. Разница между двумя
подписками отсюда честна — оба плеча идут одним маршрутом. Абсолютная
задержка — нет, и клеймо не даёт об этом забыть при переносе числа в реестр
замеров.

## Секреты

Токен GitHub живёт в «Секретах» Colab под именем `GH_TOKEN` и в файлы
репозитория не попадает. Права токена: только этот репозиторий,
`Contents: Read and write`.
